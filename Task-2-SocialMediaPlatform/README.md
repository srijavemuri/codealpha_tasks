# ConnectSpace 💜 — Social Media Platform

A simple social media platform built as part of the CodeAlpha Full Stack Development Internship.

## Features
- User registration and login
- Create and view community posts
- Like posts
- Add and view comments
- Responsive purple-themed interface

## Technologies Used
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- HTML, CSS, JavaScript

## Setup
1. Install Node.js.
2. Run `npm install`.
3. Create a `.env` file with your MongoDB connection string as `MONGO_URI=your_connection_string`.
4. Run `node server.js`.
